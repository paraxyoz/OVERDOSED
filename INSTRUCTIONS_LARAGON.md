# 🚀 ИНСТРУКЦИЯ: КАК ЗАПУСТИТЬ САЙТ С БАЗОЙ ДАННЫХ В LARAGON

---

## 💡 Что имел в виду твой друг Лёха?
Когда ты просто дважды кликаешь по файлу `index.html` на рабочем столе, сайт открывается как файл:  
`file:///C:/Users/.../index.html`.  
В таком режиме никакой сервер и никакая **база данных работать не могут**, потому что файлы открыты напрямую в браузере, а не через веб-сервер.

**Лёха имел в виду следующее:**
В колледже/универе на компьютерах установлен **Laragon** — это локальный веб-сервер (включает Apache, PHP и СУБД MySQL).  
Когда ты копируешь папку сайта внутрь папки `www` в Laragon и запускаешь сервер, твой сайт становится настоящим веб-сайтом, открывается по адресу **`http://overdosed.test`** или **`http://localhost/overdosed`** (без `C:/Users/...`).  
И теперь сайт работает на **PHP** и подключён к **базе данных MySQL**! Если в базе изменить цену товара или название, сайт сразу покажет новые данные!

---

## 📁 Что было сделано для твоего сайта:
1. **`database.sql`** — файл дампа базы данных (создаёт БД `overdosed`, таблицу `products` и заполняет товарами).
2. **`db.php`** — скрипт подключения к MySQL с авто-созданием базы и таблицы (даже если забудешь импортировать SQL-файл, скрипт сделает всё сам при первом открытии!).
3. **`index.php`** — главная страница магазина, которая берёт товары напрямую из базы данных MySQL (`SELECT * FROM products`).
4. **`product.php`** — страница конкретного товара (`product.php?id=1`), берущая подробную информацию, цены и характеристики из БД.
5. **`admin.php`** — панель управления, где можно в 1 клик прямо в браузере менять цены, названия, добавлять новые товары или удалять их.
6. **`api/products.php`** — API эндпоинт, отдающий товары из БД в формате JSON.

## 🛠️ Пошаговая инструкция к паре / зачёту

### Шаг 1. Скопировать сайт в папку Laragon `www`
1. Найди, где установлен Laragon (обычно это `C:\laragon`).
2. Внутри есть папка **`www`** (полный путь: `C:\laragon\www`).
3. Скопируй туда всю папку сайта и назови её, например, **`overdosed`**.  
   Получится путь: `C:\laragon\www\overdosed`.

### Шаг 2. Запустить Laragon
1. Запусти программу **Laragon** (ярлык на рабочем столе или в меню Пуск).
2. В окне Laragon нажми большую кнопку **«Start All»** (Запустить всё).  
   *Должны загореться зеленым Apache и MySQL.*

### Шаг 3. Открыть сайт в браузере
1. Открой любой браузер (Chrome, Edge, Яндекс).
2. В адресную строку введи:
   ```text
   http://overdosed.test
   ```
   *или, если автодомены не настроены:*
   ```text
   http://localhost/overdosed
   ```
3. Готово! В адресной строке отобразится красивый адрес сайта без `C:/Users/...`!

## 🗄️ Шаг 4. База данных (Как показать преподу)

### Способ 1. Через phpMyAdmin (Классический способ по учёбе)
1. В окне Laragon нажми кнопку **«Database»** (или открой в браузере `http://localhost/phpmyadmin`).
2. Логин: `root`, пароль: *пустой* (просто нажми «Войти»).
3. Слева найди базу данных **`overdosed`** и нажми на таблицу **`products`**.
4. Ты увидишь строки с товарами!
5. **Как показать работу:**
   - Нажми дважды на цену товара (столбец `price_rub`) и измени, например, с `2500` на `9999`.
   - Вернись на вкладку с сайтом (`http://localhost/overdosed`) и обнови страницу (F5).
   - **Цена на сайте изменилась!** Препод доволен, цель достигнута.

*(Примечание: если ты хочешь вручную импортировать базу, в phpMyAdmin нажми вкладку «Импорт» -> «Выберите файл» -> укажи `database.sql` из папки сайта -> нажми «Вперед»).*

### Способ 2. Через встроенную админку
Мы добавили для тебя страницу управления:
```text
http://localhost/overdosed/admin.php
```
Там можно прямо в браузере вводить новые цены, нажимать галочку «Сохранить», добавлять новые товары через форму или нажать кнопку «Сбросить базу».
